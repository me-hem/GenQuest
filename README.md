# GenQuest

**Your world. Your next adventure.**

GenQuest is a local-first CLI that uses an open-weight model through Ollama to suggest real-world quests that help people step away from screens.

## Features
- Personalised quest generation using age range, occupation, environment, time, interests, preferred setting, energy level, and access needs.
- Three quest options generated by a local model.
- Basic validation for structure, setting constraints, common safety red flags, time limits, and diversity.
- Built-in fallback quests when local AI is unavailable or output fails validation.
- Reflection prompt after the quest.
- No account, database, or hosted AI API required.

## Requirements
- Python 3.10+
- Ollama
- Model: `qwen2.5:1.5b-instruct`

## Setup (Ubuntu)
```bash
cd GenQuest
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
ollama pull qwen2.5:1.5b-instruct
python3 main.py
```

Initial package/model downloads require internet. After installation, requests go to the local Ollama service at `http://localhost:11434`; no cloud AI API is used. If Ollama is unavailable, built-in quests are used.

## Stack
Python, Rich, Requests, Ollama, Qwen2.5 1.5B Instruct.

## Open innovation
A locally run open-weight model makes the core experience adaptable and usable without a hosted AI API at runtime. Python validates the response structure and provides fallback quests.
